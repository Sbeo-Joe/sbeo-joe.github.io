Anthropic이 경쟁 AI 기업 xAI의 모회사 SpaceX와 컴퓨트 공급 계약을 체결했다. 테네시주 멤피스의 <mark>Colossus 1</mark> 데이터센터 전 용량을 임차하는 이 계약으로, 클로드 코드(Claude Code) Pro·Max 사용 한도가 즉시 <mark>2배</mark>로 확대됐다.

## 핵심 포인트

- Anthropic이 SpaceX의 Colossus 1 데이터센터 전 용량 임차 — xAI 인프라를 경쟁사가 공유하는 전례 없는 구조
- Claude Code Pro·Max 이용 한도 즉시 2배 확대, 기업 고객 유치 경쟁력 강화
- Anthropic, SpaceX의 <span class="hl-blue">궤도 데이터센터</span> 구상에도 관심 표명 — AI 인프라 전쟁이 우주로 확장

## 동맹의 역설 — 경쟁사의 인프라를 빌리다

가장 기묘한 점은 딜의 구조 자체다. Anthropic의 주요 경쟁자 가운데 하나는 일론 머스크가 창립한 <span class="hl-red">xAI</span>이고, 그 xAI의 모회사가 바로 이번 계약의 상대방인 SpaceX다. Colossus 1은 원래 xAI의 `Grok` 모델 훈련을 위해 구축된 메가 데이터센터로, <mark>10만 개</mark> 이상의 엔비디아 H100 GPU를 탑재한 것으로 알려져 있다.

왜 Anthropic이 경쟁사의 인프라를 선택했는가? 이유는 단순하다 — <span class="hl-red">컴퓨트 공급 부족</span>이다. AI 모델 훈련과 추론에 필요한 GPU 클러스터 확보는 현재 AI 산업의 최대 병목이다. Anthropic은 구글(GOOGL)과 아마존(AMZN)으로부터 총 <mark>$7.5B</mark> 이상의 투자를 유치했지만, 독자 데이터센터 구축에는 수년의 시간이 필요하다. SpaceX의 기존 인프라를 임차해 즉각적인 컴퓨트 용량을 확보하는 전략이다.

Barron's 는 이번 딜이 머스크의 xAI에 잠재적 문제를 일으킬 수 있다고 분석했다. xAI가 경쟁사인 Anthropic에 간접적으로 컴퓨트를 공급하는 셈이기 때문이다. 그러나 머스크 입장에서는 이미 구축된 Colossus 1의 유휴 용량을 수익화하는 실리를 택한 것으로 보인다. Colossus 2 구축이 진행되는 동안 기존 인프라를 최대한 활용하는 전략이다.

## Claude Code 한도 2배의 시장 임팩트

개발자 도구 시장에서 이번 딜의 즉각적 효과는 분명하다. Anthropic은 계약 체결 직후 Claude Code Pro·Max 플랜 사용 한도를 <mark>2배</mark>로 늘렸다. Claude Code는 AI 코딩 어시스턴트 시장에서 GitHub Copilot, Cursor AI 등과 경쟁하고 있다.

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| Claude Code Pro | 기준값 | `2×` |
| Claude Code Max | 기준값 | `2×` |
| Claude Managed Agents | 표준 | Dream 모드 추가 |

한도 확대는 단순한 서비스 개선이 아니다. 대규모 엔지니어링 팀이 AI 도구를 도입할 때 가장 먼저 확인하는 것이 처리량 한도다. 이번 조치는 OpenAI의 ChatGPT Enterprise, GitHub Copilot Enterprise와의 경쟁에서 <span class="hl-blue">직접적 우위</span>를 제공한다.

Anthropic은 동시에 Claude Managed Agents의 새 기능으로 에이전트가 유휴 상태에서 관련 문맥을 미리 처리해두는 "dream" 모드를 공개했다. 장시간 태스크에서 응답 품질을 높이는 방식으로, 에이전트형 워크플로우의 실용성을 한 단계 끌어올리는 시도다.

## 우주로 향하는 AI 인프라

이번 딜에서 주목할 또 다른 조항은 <span class="hl-blue">궤도 데이터센터(orbital data centers)</span>다. Anthropic은 SpaceX가 구상 중인 저궤도 기반 컴퓨팅 인프라에 깊은 관심을 표명했다. SpaceX는 스타링크(Starlink) 위성망을 활용한 우주 데이터센터 계획을 내부적으로 검토 중인 것으로 알려져 있다.

AI 추론을 위성 인프라 위에 올린다는 구상은 현재로선 선도적이지만 전략적 함의가 크다. 지구상 어느 위치에서든 AI 서비스에 접근하는 인프라는 특히 군사·항공·해양 분야에서 게임 체인저가 될 수 있다. SpaceX가 이 분야에서 선점하면, 컴퓨트 공급망이 지구 궤도로 올라가는 시대가 현실이 된다.

## 투자 관점 분석

> "AI 인프라 전쟁에서 컴퓨트는 석유다 — 경쟁사의 주유소라도 써야 할 때가 있다."

이번 딜의 연결고리를 따라가면 수혜 구조가 보인다.

Anthropic 컴퓨트 확보 → Claude Code 한도 2배 → 기업 개발자 유입 증가 → Claude API 매출 확대 → Anthropic 기업가치 상승 → IPO 기대감 고조

가장 직접적인 수혜자는 <span class="hl-blue">엔비디아(NVDA)</span>다. Anthropic의 컴퓨트 수요 증가는 곧 GPU 수요 증가를 의미한다. SpaceX·Colossus 인프라의 지속 확장, AWS·Google Cloud의 Anthropic 지원까지 더하면 GPU 수요의 구조적 성장이 확인된다.

반면 <span class="hl-red">OpenAI와 xAI</span> 에게는 복잡한 신호다. Claude Code 기반 개발 워크플로우를 기업에서 먼저 선점하면, 이후 엔터프라이즈 계약에서 강력한 고착(lock-in) 효과가 발생한다. Anthropic이 컴퓨트를 확보할수록 Claude의 기업 침투율은 빠르게 높아진다. 앞으로 6개월이 AI 코딩 도구 시장의 승부처가 될 것이다.
